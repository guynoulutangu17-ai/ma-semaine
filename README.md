# Ma semaine

Horaire des cours, rappels et planning d'étude pour la mention Math, Stat et Info (L1 LMD A et B), premier semestre 2026-2027. L'option « Mon horaire » permet d'importer un autre horaire (photo ou saisie à la main) avec les matières Anglais, Statistique, Logique et E.O.E.

Application web installable : ouvrez l'adresse du site dans Chrome (Android) ou Safari (iPhone), puis « Installer » ou « Sur l'écran d'accueil ».

- Les cours peuvent être ajoutés à l'agenda du téléphone (fichier .ics généré dans l'application, rappel au choix).
- Jour pair / jour impair pour les salles : rang du jour dans la semaine (lundi = 1 … samedi = 6).
- Mode hors connexion : le réseau est essayé d'abord (3 s), puis la copie gardée sur le téléphone.

Pour publier une nouvelle version, changez le numéro de `CACHE` dans `sw.js`.
