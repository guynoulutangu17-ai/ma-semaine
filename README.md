# Ma semaine, L1 LMD B

Horaire des cours, rappels et planning d'étude de la L1 LMD B (Mention Math, Stat et Info), premier semestre 2026-2027.

Application web installable : ouvrez l'adresse du site dans Chrome sur Android, puis touchez « Installer ».

Pour publier une nouvelle version, changez le numéro de `CACHE` dans `sw.js`.
